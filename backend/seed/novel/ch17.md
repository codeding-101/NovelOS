# 第17章 天机阁的地图

五月十八，听雨楼。

听雨楼在青云镇北头，黑底金字的匾，三层木楼，白天开门做生意，卖茶、卖酒、卖消息。楼里永远有雨声——后院引了一道细水，从三层的竹管滴下来，落在石臼里。

林默进楼时，正赶上一群行商在堂里高声说笑。他绕过他们，把昨夜从死人身上搜出的半块木牌放在柜台上。

掌柜看了一眼木牌，抬眼看他：“公子要什么？”

“我要见你们少阁主。”

掌柜把木牌推回来：“楼里的规矩，先付价。”

“价我出。”林默说，“西祠两个字，换一个见面。”

掌柜沉默了一会儿，转身进了里间。林默在堂里等到第三壶茶凉透，才被人引上三楼。

三楼只有一间屋。窗半开着，风把雨声吹得满屋都是。苏月宁坐在窗边的矮几后，一身月白长衫，手边摆着一卷地图。

“你比我算的晚了两天。”她说。

“血河教在青云镇外设阵。”林默把木牌和那包暗红的粉末一起放在几上，“阵里烧的是人血，这半个月镇上失踪的，明面上三个，暗里不知多少。他们说阵要往西搬二十里，木牌上刻着西祠。”

苏月宁拿起粉末，凑到鼻尖闻了一下，眉头微皱。

“是聚血阵的阵灰。”她把粉末放下，“西祠我知道。那是血河教在青州一带的旧祠，二十年前被正道清过一次，人没杀绝。”

“我要西祠的图。”

“我没有西祠的图。”苏月宁把手边的地图推过来，“我有这个。”

那是一张残图。纸发黄，边缘烧焦过，缺了右下角一大块。图上用细墨线画着山势，中央一片山谷没有名字，四周却密密麻麻标着十三道虚线，每道虚线尽头都画着一个小小的圈。

“这是什么？”

“玄天秘境的外围。”苏月宁的手指在图上划过，“六十年一开，开的时候会先在山谷外放出十三道气眼。气眼一动，人就进得去。进了秘境，一个人只能带走一样东西——记住，只能一样。”

林默盯着那张图：“你要什么？”

“秘境里的东西，你先拿到手，再分我。”苏月宁说，“我要的是里面刻着字的东西，石板、铁卷、骨简都行。你那份，我不动。”

“你就这么信我？”

“我不信你。”苏月宁笑了一下，“我信你要报仇。一个要报仇的人，不会在秘境里偷懒。”

林默把残图折好收进怀里。他起身要走，忽然停了一下。

“坊间都说，天机阁阁主三年前失踪了。”

苏月宁脸上的笑意淡下去。她伸手合上窗，把雨声关在外面。屋里一下子静得能听见水滴落进石臼的声音。

“阁主是我师父。”她说，“三年前他去查一件事，查完就没回来。阁里长老会说我年轻，压不住事，给了我三年时间——三年之后我要是还查不清，阁主这位子就换人坐。”

“查什么事？”

“玄天裂变。”苏月宁说，“五百年前那场裂变，把天地间的灵气重新激了起来。可它不是天灾。”

林默心里一跳。他想起父亲，想起四月十五那张写着“死因无档”的薄纸。

“我父亲的事，和这个有关？”

苏月宁没有答。她重新把窗推开，让风进来。

“去把西祠查清。”她说，“秘境开启之前，血河教一定会动手。你活着回来，我就告诉你下一句。”

林默把残图按在胸口，下楼去了。
