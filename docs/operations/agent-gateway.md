# 离线 Agent 接入与恢复

适用版本：schema `0007_agent_gateway`，任务协议 `1.0`，Agent 配置 `offline_v1`。

本工作包开放外部进程主动连接平台的任务接口。参考客户端只做字符数与输入哈希校验，不调用模型。尚未开放供应商 API、付费调用或供应商 token 用量上报；不能把协议验收结果当成 AI 创作、文学审查或朱雀检测报告。

## 网站操作

1. 在“执行者与路由设置”新增外部 Agent，勾选“启用离线 Agent 协议”及“在路由规则中启用”，声明能力并保存。离线协议不关联供应商凭证或价格。
2. 选择作品，把该 Agent 加入允许列表并保存。需要自动路由时再调整首选顺序；自动选中仍需用户签发任务令牌并运行客户端。
3. 在任务中心选择当前输入版本与该 Agent，创建任务。参考客户端仅支持“分析”类型。
4. 在“Agent 任务授权”签发令牌。网站可设置 1—24 小时有效期，API 支持 5 分钟至 24 小时。任务必须处于排队、重试等待或暂停状态；签发不会自动恢复暂停任务。
5. 令牌只在签发响应返回一次，复制交给你控制的客户端。未保存时先撤销，再签发；同一任务最多一个有效令牌，累计保留最多 32 份授权记录。
6. 查看候选结果和执行记录。令牌撤销会暂停该令牌正在执行的任务；已完成任务保持完成。恢复任务前，检查输入、授权、期限和剩余尝试次数。

更换 Agent 进程时，若仍使用同一执行者登记项，可撤销旧令牌、签发新令牌并恢复；新尝试可读取最近检查点。若要改为另一个执行者登记项，需要新建任务，已有任务不静默改派。检查点能否被新执行者理解取决于其内容协议。

## 参考客户端

在仓库根目录运行，使用 Python 标准库，无模型 SDK 依赖：

```powershell
.\backend\.venv\Scripts\python.exe scripts\offline_agent_client.py --origin https://novelos.example.com --task-id <任务ID> --state <私有目录>/agent-state.json
```

运行后通过隐藏输入粘贴令牌；自动化可从私有环境变量 `NOVELOS_AGENT_TOKEN` 传入，不要写入命令行参数、提交到仓库或留在日志中。客户端只接受单一 HTTPS 源，拒绝路径、URL 凭证、查询参数、重定向和环境代理。仅本机验收可添加 `--allow-insecure-loopback` 使用 `http://127.0.0.1:<端口>` 或 IPv6 回环。

状态文件原子保存领取凭证与待提交结果，不保存 Bearer 令牌，但仍包含私人内容和执行权限，应放入仅自己可访问且不会提交的目录。文件绑定服务器、任务和授权指纹；更换令牌须使用新状态文件。不要让多个进程同时使用一份状态文件。

网络断开后用同一命令、令牌和状态文件重试：若结果已保存，先重交同一结果，服务器按提交键去重；否则重新领取当前有效尝试并恢复检查点。若令牌撤销／过期、租约过期、任务暂停或结果被隔离，客户端不会自行恢复或无限重试，须回网站处理。已完成且回执丢失的结果重交仍要求令牌有效。

## 接口与权限

用户管理接口使用登录会话、CSRF 和来源校验：

| 前缀 `/api/v1/tasks/{task_id}/agent-grants` | 用途 |
| --- | --- |
| `GET` | 授权名称、标识、到期与撤销时间，不返回密钥或哈希 |
| `POST` | `expected_version`、`name`、`expires_seconds` 签发一次性可见令牌 |
| `DELETE /{grant_id}` | 撤销授权；运行中的对应尝试暂停并失效 |

Agent 接口使用 `Authorization: Bearer <任务令牌>`，不接受用户 Cookie 代替 Agent 身份。所有写请求仍拒绝不匹配的 Origin 或跨站浏览器请求；普通客户端不需要发送 Origin。

| 前缀 `/api/agent/v1/tasks/{task_id}` | 用途 |
| --- | --- |
| `GET` | 当前状态、版本、次数、原因及最近检查点 |
| `POST /claim` | 返回输入快照与 `TaskEnvelope`；同授权接续有效尝试时轮换租约令牌 |
| `POST /heartbeat` | `attempt_id`、`lease_token` 续期 |
| `POST /checkpoints` | 保存有序、可去重的检查点 |
| `POST /results` | 提交 `ResultEnvelope`，返回候选／隔离回执 |

协议结构和大小限制见 [任务中心指南](task-runtime.md) 及 `backend/app/platform/task_protocol.py`。领取有效期 60 秒，长任务建议每 20 秒续期，每次尝试最长 1 小时，且不能超过任务总期限。重连接续不增加尝试次数，但旧租约令牌立即失效；过期后的恢复生成新尝试并消耗次数。Worker 必须在线以扫描过期任务。离线 Agent 过期后暂停，不自动重复执行外部进程。

令牌只绑定一个任务和执行者，不能读取其他作品、供应商密钥、预算接口，不能创建／恢复／取消任务，也不能写正文、正式记忆或定稿。授权绑定不可变，数据库仅保存令牌哈希。撤销与回报按同一任务事务锁排序，每次操作在事务内重新验证授权；已撤销或过期的令牌不能靠旧租约提交。

`permissions.external_calls=false` 指不授权调用供应商或其他外部服务，允许连接本任务网关。`usage` 只接受零值与 `not_applicable`，预算预留也拒绝离线协议。平台能约束自己的入口和状态提交，无法隔离或监控用户自行运行的远程进程，也不能证明它没有私下使用其他服务。因此仅向可信进程交付任务正文，并在该进程所在环境实施所需的网络和文件权限限制。

候选不会自动改变正文；检测缺失时不开放定稿。真实模型适配、付费用量解析、每任务子预算、供应商月度额度及朱雀检测继续按后续工作包交付。验收记录见 [开发执行记录](../planning/execution-status.md)。
