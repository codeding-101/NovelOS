# 中文正式记忆检索基础

本工作包提供只读 API，为后续摘要复用与上下文推荐准备检索基础。未接入网页推荐按钮、自动选择、摘要生成或真实模型；现有字面检索继续可用。数据库 schema 保持 `0014_task_contexts`。

已登录用户调用 `GET /api/v1/works/{work_id}/memory/retrieve?q=林舟%20船医&limit=20`，可选 `at` 指定故事时点。关键词最多 256 字符，结果数 1—50。权限沿用作品用户接口，Agent 任务令牌不能访问作品记忆库。

响应包含 `algorithm`、归一前去除首尾空格的 `query`、`scanned`（当前有效候选数量）、`scan_limit`、`matched`（正分候选数量）与 `items`。每项为完整 `memory`、`score` 和 `matched_terms`。结果只供选择，调用不会创建快照、改变正式记忆或启动任务。

算法 `lexical_zh_bigram_v1` 使用 NFKC、大小写归一、中文相邻双字及英文数字词。标题／条目标识的匹配词各加 3 分，正文匹配词各加 1 分；完整查询出现在标题／标识时再加 6 分。重复词不重复计分。相同分数按条目标识排序，零分不返回。分数不是概率或事实正确率，不具备同义词、别名消解和语义理解能力。

范围只含该作品的现行正式记忆。来源版本发生变化时排除整条记忆；指定时点后，结构化状态按半开区间筛选，未标时点的普通文字记忆保留且不推断时间。当前实现最多扫描 1,000 条有效记忆；超限返回 409，提示改用字面检索，不默默截断候选集合。该边界不是百万字规模验收。

检索是读时观察，不是执行授权：用户选取结果后，保存快照和任务执行仍按原流程重新校验依据。并发编辑可能使刚返回的结果失效；不能以检索结果绕过这些检查。接口不记录查询正文到审计，不新增索引、外部服务或依赖。

评估样本涵盖中文人物身份、地点规则和中英混合全角文本的首位命中，以及重复文字不抬高分数。小型确定性样本仅用于回归，不代表真实小说语料召回率。分层摘要、中文大样本评估、检索索引、网站推荐交互和自动装配继续待办。
