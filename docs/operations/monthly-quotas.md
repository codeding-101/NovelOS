# 共享月度 token 配额

适用版本：schema `0010_monthly_quotas`。真实模型调用保持关闭，当前验收只使用本机模拟服务。

## 网站操作

从控制台进入“管理月度配额”，按实际共享额度的账户或服务创建配额，填写名称、每月 token 上限和月界时区。支持 UTC 或北京时间（固定 UTC+08:00）的自然月，不支持滚动 30 天或账单周年日。时区创建后固定，上限可以调整；零表示没有可用额度。

把使用同一账户额度的模型 API 执行者绑定到同一配额。配额跨作品、跨任务和执行者共享，不按每个执行者重复授予额度。绑定必须在该执行者第一次调用预留之前完成，已有调用账目的执行者不能补绑；重复绑定同一配额幂等返回。当前不支持解除、改绑或删除，以免历史消费从配额中消失。首次绑定与预留通过执行者锁串行检查。

尚未绑定的执行者仍只受作品、任务预算约束。平台不能自动推断哪些凭证或执行者共用供应商账户，也不能统计平台外的消费。当前只支持已配置模型协议的 API 执行者，不包含付费 Agent 或朱雀检测适配。

页面显示本月已结算、所有月份仍占用、剩余额度和未知数量；用量与占用达到上限的 80% 时提示。保存上限使用版本校验；并发消费、绑定或编辑可能使保存冲突，输入保留，点击“载入最新配额”后核对再保存。配置更新不会自动恢复暂停任务。

## 与其他预算的关系

路由预览和新建任务会排除配额不足或存在未知用量的执行者。领取、恢复、预留和发送前再次检查，领取受阻暂停为 `MONTHLY_QUOTA_EXCEEDED`，不消耗尝试次数；发送前跨月、缺少归属或额度受阻也使用该原因。

任务预算、作品预算和已绑定的月度配额共同生效。月度上限不降低按冻结价格记入的费用，不自动切换免费／付费模式，也不会授予正文外发权限。提高其中一层额度不会提高其他层额度。

## 月界与未知用量

本地计量固定为输入 token 加输出 token，预留使用模型完整上下文上界，结算采用已验证的回报用量。它不是供应商免费额度的通用计量规则；缓存、检测字符、服务赠送、账户外消费或特殊计价仍须在实际适配时核验。

调用首次预留时保存不可修改的配额和月份归属：

| 调用状态 | 配额行为 |
| --- | --- |
| RESERVED | 按预留 token 占用；跨月仍占用，但不能在新月份发送，须暂停释放再恢复 |
| DISPATCHED | 按预留占用，包括跨月尚未结算的调用；重复登记不重发 |
| UNKNOWN | 跨月继续占用，并阻止共享配额内所有执行者新增调用，直至对账 |
| SETTLED | 按原预留月份累计实际输入加输出；迟到结算不会改记到收到响应的月份 |
| RELEASED | 不计消费，不占用额度 |

月初只改变当前月份查询，不删除任何历史记录，也不释放进行中或未知调用。跨月持有的调用照样计入当前可用额度的占用，这是保守限制。旧月调用确认后，其实际消费保留在旧月，当前占用释放。此归属是平台本地规则，不宣称等于供应商账期。

降低上限不撤回已发出的请求；实际用量超过上限仍照实结算并显示超额，禁止后续调用。UNKNOWN 在对应作品的 [预算中心](work-budgets.md) 核对；对账既更新作品账目也影响配额聚合，不额外维护第二套可漂移的消费余额。配额页面的调用列表可分页浏览各月记录，配置历史展示最近 20 条，API 支持分页。

## API 与迁移

所有路由沿用用户登录、CSRF 和来源校验，Agent Bearer 不能操作。前缀 `/api/v1/quotas`：

| 方法与路径 | 功能 |
| --- | --- |
| `GET /` | 配额概况列表，支持 offset／limit，单页最多 100 |
| `POST /` | name、timezone、limit_tokens、request_key；同键同配置返回原记录 |
| `GET /{id}` | 当前月聚合、占用、绑定及配置版本 |
| `PUT /{id}` | expected_version、limit_tokens；变更留审计 |
| `POST /{id}/bindings` | expected_version、executor_id；固定归属 |
| `GET /{id}/calls` | 跨月调用记录及作品名称，支持分页 |
| `GET /{id}/events` | 配额创建、绑定、调额审计，支持分页 |

上表 `/` 表示前缀本身，无额外尾斜线。token 上限只接受 `0` 至 `10^12` 的整数，不接受布尔值。账本变化也更新配额版本。

升级前停 API／Worker 并备份独立平台库，按 [部署指南](platform-setup.md) 显式迁移。迁移只新增配额、绑定和月份归属表，不修改既有账目，也不为历史执行者自动创建或绑定配额。绑定和调用月份归属由数据库触发器保护，不能修改或删除。降级须恢复升级前备份。

朱雀每月 50 万 token 是用户提供的后续接入要求，本轮没有核验供应商实际额度、建立真实朱雀账目或返回检测报告。100% 人工特征定稿要求继续保持，不能以本地配额或模拟用量代替检测证据。参见 [ADR 0010](../decisions/0010-monthly-quotas.md) 和 [执行记录](../planning/execution-status.md)。
