# 任务中心与中断恢复

适用版本：M3／M4 基础，schema `0013_context_snapshots`，任务协议 `1.0`。

[上下文快照](context-snapshots.md) 已开放离线组装和复查，但本版尚未绑定到任务协议或执行请求。保存或复查快照不会创建、领取或恢复任务，现有任务不会自动追加这些记忆。执行时快照校验将在后续工作包接入。

## 网站操作

1. 按 [部署指南](platform-setup.md) 升级独立平台库并启动 API、Worker 和网站，登录后打开“任务中心”。
2. 选择作品和已保存的当前输入版本，填写任务目标。先在作品空间创建资产，再为它创建任务。
3. 选择执行者：人工支持分析、起草、修订、审查和研究；本地流程校验只核对字符数、非空行数和输入哈希，不执行模型创作或文学质量审查。
4. 可设置最多尝试次数（1—5，默认 3）和一个前置任务。网站列出该作品最近 100 个任务，API 支持分页和最多 20 个依赖。
5. 人工任务点击领取后查看输入、填写进度并保存检查点；完成后提交候选结果。本地任务由在线 Worker 自动领取。
6. 查看执行记录、检查点和候选／隔离结果。接收候选不改变正文版本、正式记忆或定稿状态。

刷新页面后重新选择作品和任务，点击接续可轮换领取凭证并读取已保存的检查点。尚未保存的文本只在当前页面内存中；离开页面前应保存进度。当前人工检查点保存进度说明，候选正文须单独提交，进度保存不等于候选正文保存。

## 状态、期限与恢复

| 状态 | 行为 |
| --- | --- |
| QUEUED | 等待前置任务成功、执行者领取 |
| RUNNING | 持有当前执行尝试的有效凭证，允许心跳、检查点和结果提交 |
| RETRY_WAIT | 本地执行临时失败或领取过期后，按尝试次数指数退避；受总次数限制 |
| PAUSED | 用户暂停、人工领取过期、结果不完整或依赖失败，等待人工处理 |
| SUCCEEDED | 完整候选已接收，不代表内容正确、已采纳或已定稿 |
| FAILED | 次数／期限耗尽、输入过期或结果范围错误；保留记录 |
| CANCELLED | 用户取消，停止接收本次执行的有效成果 |

领取有效期为 60 秒，网站每 20 秒续期；单次尝试最长 1 小时。网站任务总窗口为 24 小时，API 可设为 60 秒至 7 天。休眠、断网或关闭页面可能让人工领取过期；Worker 会将其暂停，恢复后重新领取会消耗一次尝试。刷新后的有效接续不增加尝试次数，但会立即使旧页面的领取凭证失效。

暂停和取消均使当前尝试失效。恢复只能操作仍有次数和时间的暂停任务；输入正文已改变或前置任务失败／取消时，须核对并新建任务。最终状态不可重新打开。依赖不可修改且只允许新任务依赖已存在的同作品任务，避免循环。

取消与结果同时到达时，以首先完成的有效事务为准；迟到结果隔离保存，不让取消后的任务变成功。正文版本在领取及提交时检查；若用户已经保存新正文，旧输入结果不得生效。

## 协议与接口

下表接口使用现有用户登录会话，写请求须带 CSRF 与合法来源；Agent 领取和回报使用独立的 [任务专属网关](agent-gateway.md)。具体字段约束见后端 `app/platform/task_protocol.py` 及应用 OpenAPI schema。

| 接口（前缀 `/api/v1`） | 用途 |
| --- | --- |
| `GET /executors` | 已启用执行者与任务能力 |
| `POST /tasks` | 创建任务；同作品 `request_key` 与相同内容重试返回原任务，改内容返回冲突 |
| `GET /tasks?work_id=…&offset=0&limit=50` | 分页读取任务，单页最多 100 |
| `GET /tasks/{id}` | 状态、版本、执行记录、最新检查点与结果摘要 |
| `PUT /tasks/{id}/budget` | 按任务版本调整未结束模型任务的累计费用／token 上限，不自动恢复 |
| `POST /tasks/{id}/claim` | 人工领取，返回 `TaskEnvelope` |
| `POST /tasks/{id}/takeover` | 带 `expected_version` 接续有效人工尝试，轮换凭证 |
| `POST /tasks/{id}/heartbeat` | 当前尝试续期 |
| `POST /tasks/{id}/checkpoints` | 保存连续递增检查点 |
| `POST /tasks/{id}/results` | 提交 `ResultEnvelope`，返回不可变回执 |
| `GET /tasks/{id}/submissions/{submission_id}` | 读取候选或隔离结果 |
| `POST /tasks/{id}/control/{pause,resume,cancel}` | 按 `expected_version` 控制任务，状态变化后冲突拒绝 |

`TaskEnvelope` 包含输入正文快照及 SHA-256、任务类型／目标、依赖、尝试代次、截止时间、当前检查点和权限。领取凭证只在领取／接续响应返回，数据库仅存哈希，审计和任务详情不包含凭证。权限明确禁止直接写资产、定稿、外部和付费调用。

`ResultEnvelope` 包含协议版本、任务／尝试／执行者标识、领取凭证、提交幂等键、结果状态、完成原因、产物、输入版本证据、警告和用量。公共人工／离线 Agent 接口的用量必须为零并标记 `not_applicable`，这不是预算账本。完整成功结果必须有非空产物、正确产物类型和精确输入版本证据；空结果、截断和不完整成功会保留为 PARTIAL 并暂停任务。

检查点单份最多 32 KiB，每次尝试最多 1000 个，序号必须连续；相同序号相同内容重试返回原记录。结果整体最多 2 MiB、8 个产物，每次尝试最多 16 份回执；相同提交键与内容返回原回执，不重复变更任务。同键不同内容拒绝。检查点、结果和依赖有数据库不可变保护。

本机模型协议测试由内部服务提交 `usage.accounting=settled`，用量必须与同尝试的已结算调用一致，并与候选在同一事务提交；公共人工和 Agent 接口拒绝这种用量。`MODEL_PREFLIGHT_FAILED` 表示发送前检查失败；已存在未知调用时统一使用 `BUDGET_UNCERTAIN`。配置及测试边界见 [模型协议指南](model-api-rehearsal.md)，不代表真实模型已启用。

## 验证和当前边界

模型任务新增 [累计任务预算](task-budgets.md)，各次尝试共享已结算及占用金额。`TASK_BUDGET_EXCEEDED` 表示任务额度未配置或不足；领取阻断不消耗尝试，调整额度后须手动恢复。作品预算仍同时生效，未知费用不因调额释放。

已绑定的执行者还受 [共享月度配额](monthly-quotas.md) 约束。`MONTHLY_QUOTA_EXCEEDED` 表示额度不足、共享未知用量或发送前月份归属受阻；领取阻断不消耗尝试，跨月或调额不会自动恢复任务。

用户可在 [记忆与审核](memory-review.md) 中关联同作品已接收的任务候选及其输入版本，另行提出记忆变更。任务成功不会自动创建或批准记忆，Agent 网关也未获得正式记忆写入权限。

双数据库测试覆盖并发领取、取消与结果竞态、重复提交、过期恢复、接续凭证撤销、输入过期、依赖隔离、事务回滚、重试耗尽和队列阻塞。浏览器覆盖人工进度保存／刷新接续／暂停恢复、候选不修改正文、本地完成和取消；证据见 [执行记录](../planning/execution-status.md)。

首个工作包之后已增加 [作品预算与未知费用对账基础](work-budgets.md)，取消和过期恢复会释放未发起预留、保留可能发生费用的调用；未知费用未核清时不允许恢复该任务。人工与本地任务的协议用量仍为零。

当前已增加 [执行者登记与能力路由](executor-routing.md) 及 [离线 Agent 身份与参考客户端](agent-gateway.md)。任务中心可选择“按作品规则自动选择”；创建时保存选择依据，领取时重新检查启用、可用、能力和作品规则，变化后暂停为 `EXECUTOR_BLOCKED` 且不增加尝试。Agent 撤销会暂停为 `AGENT_REVOKED`；租约过期也会暂停，由用户恢复。仍未实现真实模型适配、完整 Agent SDK 或候选采纳入口。不存在真实朱雀报告，也没有开放定稿。后续继续价格与用量解析和受约束适配器；真实调用另按用户提供的配置和额度授权执行。
