# 执行者登记与作品路由

适用版本：M3，schema `0008_model_api`。可以实际路由人工、本地校验及 `offline_v1` Agent 任务；公网模型 API 和其他 Agent 协议仍处于登记和配置检查阶段。本机测试例外见 [模型协议指南](model-api-rehearsal.md)。

## 执行者设置

从控制台进入“执行者与路由设置”。内置人工执行者支持分析、创作、修改、审查和研究；本地流程校验只能分析字符数、非空行数和哈希，不允许通过能力配置把它变成创作执行者。

可登记模型 API 或外部 Agent，填写名称、声明能力、排序优先级、用户标记的可用状态、凭证引用、上下文上限和输入／输出价格。默认不启用新登记项。可用状态来自用户声明，不代表平台已检测到在线，也不是接口兼容性或模型质量保证。

凭证先在控制台加密保存，再在此选择名称。API 引用模型 API 类型凭证，普通 Agent 登记引用外部 Agent 类型凭证；不接受类型不匹配或不存在的引用。删除凭证不会抹掉执行者历史，但后续检查会提示缺少凭证。

勾选“启用离线 Agent 协议”后不使用供应商凭证或价格，仅允许零外部用量的候选回报；启用登记项并加入作品允许列表后即可创建任务。每个任务另由用户签发专属令牌，操作见 [Agent 接入指南](agent-gateway.md)。这不表示已接通模型或平台能隔离外部进程。

价格按每百万 token 的币种单位输入，最多六位小数；两项均空表示未知，填写时须同时有输入价、输出价和币种。上下文上限为空也视为未知。当前最多登记 100 项（含内置项），通过编辑和停用管理，不提供删除入口。

编辑使用版本检查，冲突时不覆盖服务器配置。登记使用幂等请求标识，相同请求重试不会生成多个执行者；相同标识提交不同配置会被拒绝。

API 登记可额外保存 `api_config`，包括完整地址、模型、输出上限及超时。公网配置始终受 `MODEL_API_DISABLED` 阻断；仅测试环境的回环模拟服务可执行，其声明上下文全部计入预留，并冻结任务创建时的配置。普通开发和生产环境不会因保存配置而发送作品或消费。

## 作品规则

选择作品后设置允许列表和首选顺序。默认允许人工和本地校验，自动选择首选人工；空允许列表会阻止创建和领取新的任务。显式选择执行者也要遵守允许列表、启用状态、可用状态和能力约束。

自动选择顺序为：首选列表顺序 → 执行者优先级从高到低 → 稳定标识。优先级相同仍保持确定顺序。被允许且符合约束、但未列为首选的执行者可以作为后续选择。

“允许自动选择本地流程校验”默认关闭，须用户主动勾选。本地诊断不能被当成 AI 创作：它只能匹配分析任务；创作、修改、审查和研究均不能选择它。

规则保存后用于后续创建、领取和恢复检查。已经领取并在执行的任务可正常结束；需要立即停止时到任务中心暂停或取消。排队任务继续绑定创建时选定的执行者，不因优先顺序改变而悄悄改派；若该执行者被停用、移出允许列表、标记不可用或失去能力，领取时暂停为 `EXECUTOR_BLOCKED`，不增加尝试次数。规则恢复后可人工恢复排队。

## 检查与使用

“检查已保存规则”接受任务类型、估计输入 token 和最大输出 token，返回当前可选者及每一项的排除原因。未保存的表单不会影响检查。检查不创建任务、不预留预算、不发送请求，也不自动付费。

外部候选额外检查凭证、上下文、价格、预算是否配置、币种是否匹配、未知费用和费用／token 余量。费用以整数微单位计算，输入和输出分别向上取整：`ceil(input_tokens × input_rate / 1,000,000) + ceil(max_output_tokens × output_rate / 1,000,000)`。每一币种单位为一百万微单位，API 价格字段为“每百万 token 的微单位”。

这些数字是用户给定 token 和声明价格下的规划估算，不包含分词器、隐藏提示词、供应商计费差异或免费配额解析；不能作为真实调用的成本保证。未配置适配器的 API／未启用离线协议的 Agent 有 `ADAPTER_NOT_READY` 阻断；已配置的公网 API 仍受 `MODEL_API_DISABLED` 阻断。离线协议与内置执行者一样按零供应商用量选择，不参与价格预留。当前模型协议只在测试环境预留和执行，后续真实适配器必须验证供应商输入与费用上界。

在任务中心选择“按作品规则自动选择”即可创建本地可执行任务；平台在创建时重新检查并选定实际执行者，不直接信任预览结果。锁定后若选择顺序变化，返回冲突让用户重试。无可选执行者则拒绝创建，不伪造成功。

每个新任务保留不可变的路由记录：请求的选择方式、实际执行者、规则和版本、候选顺序、声明能力、可用状态、价格及上下文参数、排除原因和预算版本。历史规则变更不会改写此记录。旧任务没有凭空补造选择历史，详情中的路由记录可以为空。创建本地任务的记录不等于对外部输入完成实际 token 估算。

## API

下表管理接口沿用用户登录、写请求 CSRF 和来源校验；Agent Bearer 只用于独立网关，不能访问管理接口。

| 接口（前缀 `/api/v1`） | 用途 |
| --- | --- |
| `GET /executors` | 登记项及声明状态，不含凭证密文或秘密 |
| `POST /executors` | 登记 API／Agent，携带 `request_key` |
| `PUT /executors/{id}` | 带 `expected_version` 更新声明；类型和标识不能改变 |
| `GET /works/{id}/execution-policy` | 读取规则，尚未保存时返回默认规则和版本 0 |
| `PUT /works/{id}/execution-policy` | 带版本保存允许列表、首选顺序及诊断选择开关 |
| `POST /executor-routing/preview` | 只读检查已保存规则和预算，不创建预留 |
| `POST /tasks` | `executor_id` 可为 `human`、`local_test`、`auto` 或允许的离线 Agent 标识 |

当前提供离线参考客户端，尚无供应商地址／协议联调、能力自动发现、健康探测、完整 Agent SDK、真实调用用量解析或供应商月度配额。M3 的真实模型执行路径仍未完成，朱雀 100% 定稿要求仍由后续阶段实现。阶段证据见 [执行记录](../planning/execution-status.md)。
