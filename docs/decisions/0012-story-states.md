# ADR 0012：显式故事区间与现行设定查询

- 状态：已接受
- 日期：2026-10-26

## 问题与决策

记忆批准版本表示平台采纳设定的顺序，不能直接当作故事时间；倒叙查询也不能恢复已被纠正的旧设定。因此在不可变提案旁增加可选、一对一的 `memory_story_states`，冻结对象、属性、取值和 `[valid_from, valid_until)` 区间。时点为作品约定的 0 至 10¹² 整数，结束可空，不从正文猜测。

时点查询只连接现行正式指针和结构化状态，再筛选区间；候选、驳回、旧版本及没有时点的条目均不参与。旧批准仍能查历史，但查询过去时点不会将其重新生效。两个真实故事阶段采用不同条目，各自保留现行批准版本。

批准在已有作品锁下，对同对象、同属性的其他现行条目检测区间重叠；相等取值也不允许重复占用。替代自身时排除自身旧版，其他条目仍检查。来源锁、依据版本及有效期沿用既有审核事务，不添加 Agent 权限。冲突可在待审核阶段保留供用户决策，批准时必须重新检查。

新增表沿用 SQLite／PostgreSQL 不可更新、不可删除触发器。创建状态和来源、提案、审计在同一事务，故障不留孤立记录。已有提案不回填任何时间；未携带状态的请求继续沿用旧内容指纹，保证升级后幂等兼容。

## 验证与限制

验证半开区间、无结束时点、过去查询不复活旧版本、开放区间闭合、候选隔离、来源复查、不同条目并发重叠、事务回滚、不可变保护、升级兼容及用户权限；网页验证填写、前后对照、查询、重叠阻断和刷新持久化。

当前对象和属性由用户指定，检查基于精确匹配，不宣称检测语义矛盾。没有统一历法、角色认知、平行时间线或自动抽取；来源后来编辑只提示复查。此工作包不把完整 M4、上下文系统或内部 Alpha 标为完成，真实调用和正文定稿继续关闭。
