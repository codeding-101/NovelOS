# ADR 0014：不可变任务绑定与边界复查

- 状态：已接受
- 日期：2026-10-27

## 决策

使用单独不可变 `task_contexts` 表绑定任务与已组装快照，避免迁移时为历史任务添加推测上下文。创建校验同作品、同输入、同目标和 READY／来源状态，快照参与路由容量计算。绑定只能与任务同时创建，不能在重试时偷偷换用新文档。

未绑定任务保持 1.0 契约及旧幂等哈希。绑定任务下发 1.1 包含确切文档和哈希，结果须明确回传 `context_ack`。客户端不能通过忽略新增字段而被标为已完成；回报不匹配保存为隔离候选。确认不是语义遵从证明。

绑定任务持有 task 锁后先获取 work 锁，再获取适用的执行者／配额／预算与资产锁。这样结算后的结果校验不会逆向获取作品锁，与创建、记忆审批和其他任务形成锁循环。创建在最终资产锁下再次校验，记录与审计同事务提交。

领取、重连、接续、续期、检查点、恢复、本机模型发送登记和结果接收均校验固定依赖。领取前失效不消耗 attempt；执行中失效不接收新进度或新的有效候选。已经持久化的幂等回执仍可读取，不能授权新执行。已经接受的候选不做破坏性追溯修改，后续失效影响另行处理。

保持短事务；发送登记到网络调用之间不能阻止任意编辑，回报再校验是必要边界。已发生的模拟用量仍结算，过期结果同时隔离；费用未知仍保持未知，不释放为虚假余额。

## 实现范围

人工、本地诊断、任务专属离线 Agent 及测试环境回环模型使用同一绑定和结果校验。网页自动填入固定输入与目标，参考 Agent 验证文档哈希并保存确认以便丢失回执重试。模型消息包含完整快照并计入原字节代理容量检查；无真实分词或公网能力扩展。

迁移保留历史，Agent 权限范围不扩大，真实调用与正文定稿继续关闭。摘要、自动检索、中文召回评估、真实窗口适配及审批规则继续分包推进。
