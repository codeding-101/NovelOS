# ADR 0008：先验证模型调用事务，再开放公网执行

日期：2026-10-25。状态：本机协议工作包已实施；公网调用未发布。

## 决策

执行者增加可空 `api_config`，历史登记保持无适配配置，原登记请求的幂等哈希保持兼容。没有自动启用模型供应商或读取旧应用密钥。

先实现文本 Chat Completions 子集：单次非流式请求、固定输入版本、声明容量和价格、上报用量解析、输出范围校验。公共模型入口保持关闭；仅测试环境的字面量回环地址可被路由和传输。普通开发及生产 Worker 在读取凭证或发送前即返回，传输层独立拒绝非回环地址。

使用既有不可变路由记录冻结任务执行配置；整个声明上下文额度作为预留 token 容量，输入与输出费用分别向上取整。字节筛选不是通用分词器证明，模拟账本不是供应商账单，不把本次验证当作真实计费保障。

调用发送登记先于网络操作提交。`budget_service.settle` 和任务候选提交共用事务：失败一起回滚，迟到用量可结算但不能重新激活取消或过期尝试。供应商请求不自动重发；响应缺失或无法解释时进入 UNKNOWN，保留占用，等待人工核对。

公共人工／Agent 入口仍不接受已结算用量，用户会话不能领取模型任务或代报模型结果。内部结果必须绑定同任务同尝试的已结算调用，并与账本 token 和金额一致。

## 后续边界

真实正文出站和消费能力须取得明确授权后单独开放，并完成公网传输、实际分词和价格验证、供应商协议差异与真实故障联调。本次代码不提供开启公网调用的环境开关，不模拟真实朱雀检测。

迁移 `0008_model_api` 只新增执行者 JSON 字段，保留作品、任务、授权和预算，不提供破坏性降级。操作与测试证据见 [模型协议指南](../operations/model-api-rehearsal.md)。
