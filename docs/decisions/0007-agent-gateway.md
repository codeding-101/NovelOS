# ADR 0007：任务专属的离线 Agent 网关

日期：2026-10-25。状态：已实施，属于 M3 的一个工作包。

## 背景

平台已有持久任务、租约、候选隔离、作品预算和执行者路由。外部进程需要可恢复的接入方式，但当前没有真实供应商适配和可信计费解析，不能直接放开付费执行或复用用户登录权限。

## 决策

- 增加 `offline_v1` Agent 登记配置，复用能力、启用／可用状态和作品允许规则。离线协议无供应商凭证、价格或计费用量，预算预留拒绝该协议。
- 由用户为单个任务签发随机 Bearer 令牌，只返回一次，数据库存哈希。不可变授权绑定任务与执行者；旧的无任务绑定 Agent 凭证不自动获得权限。
- Agent 网关与用户 API 分离，Cookie 不能代替 Agent 令牌，Bearer 不能代替用户会话。只提供状态、领取、续期、检查点和候选回报。
- 统一锁序为任务再授权，撤销及回报在事务内检查有效性；授权不能在中间件通过后绕过事务内撤销。已经提交的有效候选不因之后撤销而删除。
- 同授权重连有效尝试时轮换租约凭证，过期或暂停后由用户恢复并新建尝试。检查点及结果仍遵守原有不可变、版本检查和幂等约束。
- 参考客户端保存待提交结果后再发送；丢失回执时先重交，不先轮换租约。它禁止 HTTP 重定向及环境代理，默认要求 HTTPS，不保存 Bearer 令牌到状态文件。
- 外部进程不在平台沙箱内。权限字段是任务契约和服务端授权边界，不能描述为对远程进程的网络隔离或用量真实性证明。

## 代价与后续

任务授权需要用户操作，暂不提供自动签发、批量领取、远程进程调度或平台管理的 Agent SDK。参考客户端仅为分析型协议验收程序。真正的 API 创作、付费 Agent、价格与 token 上界、用量解析和供应商故障恢复继续单独实施，不因网关通过测试而将整个 M3 标为完成。

新增迁移 `0007_agent_gateway` 保留既有任务、执行者、路由和预算；原登记请求的幂等哈希兼容新增可空字段。迁移不提供破坏性降级，恢复旧程序需恢复升级前数据库备份。操作和验收入口见 [Agent 指南](../operations/agent-gateway.md)。
