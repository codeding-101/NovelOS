# ADR 0003：附件、可恢复派生数据与旧库导入

日期：2026-10-24。补充 [不可变草稿版本](0002-immutable-drafts.md)。

## 数据权威与 outbox

附件和原始导入文件的字节保存在数据库不可变记录中。附件首版上限 4 MiB，TXT／Markdown 原稿上限 2 MiB；存储成本和百万字规模将在 M9 实测。保留数据库字节使文件同步失败时仍能下载、导出及恢复。新版本、附件、原稿与 `projection_jobs` 在同一数据库事务提交，不先双写文件系统。

本地文件适配器只接受生成的内容哈希，校验来源、限制目标目录、使用临时文件加原子替换；同一内容重复同步幂等。文件损坏后可从数据库重建。搜索表按不可变版本 ID 建立，查询时连接资产当前版本，乱序完成的旧任务不会把检索倒退到旧正文。首版是大小写折叠后的文字包含匹配，不是向量或正式记忆检索。

任务领取使用数据库条件更新，领取令牌及 60 秒期限隔离旧执行者。成功标记和索引写入在同一事务提交。数据库故障即使发生在文件写入之后，重复执行仍安全；自动重试最多 5 次，耗尽转为失败。人工重试和整作品重建均审计。重建会使之前的领取令牌失效。任务错误只保留安全类别，不记录正文、密钥或文件系统异常全文。

这是派生资产同步队列，不替代 M3 的创作任务、费用预留和外部 Agent 权限机制。

## 版本引用

`asset_references` 绑定同一作品的两个具体版本，并标明参考或依赖。相同边重复创建返回同一标识，跨作品边被拒绝。历史边不可变，列表计算双方是否仍是当前版本。修改正文不隐式修改旧绑定；完整影响分析及修复属于 M7。

## 旧库导入

只接收管理员显式指定的本地 SQLite 路径，HTTP 不接受任意服务器路径。来源用稳定 `source_id` 标识，对受支持记录的规范 JSON 计算指纹。读取在一个 SQLite 只读快照中完成；所有新作品、章节、来源映射、审计及同步任务在一个目标事务内提交。

来源主键防止并发重复导入。相同来源与指纹返回已有报告，保持新库后续修改；来源变化会中止，首版没有隐式合并。失败不会留下部分作品。未迁入的表名列在报告中，源库继续保留。

章节按旧章号建立新草稿，逐项校验正文哈希。其他受支持创作数据保存为 `legacy_records` 原始字段，不自动转换为 CANON、已采纳灵感或正式文风规则。旧文件路径只作为来源字段保留，导入器不会跟随它们读取服务器文件。

导出格式 2 包括正文版本、原文件、附件、版本引用、来源记录及校验清单；不包含平台密钥或账户，也不是完整灾难恢复镜像。

## 验证及后续

双库验证覆盖条件领取、过期结果、重试耗尽、事务回滚、文件损坏重建、当前版本检索、附件隔离、引用约束、并发重复导入和升级补建任务。已有 M0 备份在临时新库中完成 2 部作品、52 章及 550 个导出文件的校验，源库字节未变。浏览器验证上传／下载、重建／检索、引用和来源查看。

Docker／HTTPS／持久卷的真实环境验收仍独立待办。对象存储适配、自动解析大附件、语义检索、增量旧库合并和全平台灾难恢复不包含在本阶段实现中。
