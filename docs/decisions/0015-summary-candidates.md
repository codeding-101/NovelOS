# ADR 0015：分层摘要先作为有来源的候选资产

- 日期：2026-10-29
- 状态：已接受

摘要具有压缩、解释和省略性质，不能直接当作正式事实。本阶段建立独立不可变候选记录，以概述、叙事备注和未决信息分开保存用户输入，暂不进入正式记忆和任务上下文。

支持场景、章节、分卷、全书四层。上级只引用紧邻下层已存在摘要，同时继承其全部原文版本引用；禁止循环、跨作品引用与失效来源。每份候选保存直接引用和展平依据，因此来源更新可使所有依赖它的层级标记失效，不依赖重新调用模型。

创建采用作品锁和排序资产锁，幂等、候选和审计同事务提交。完整文档保留原文版本哈希、下级文档哈希与自身哈希。JSON 引用经服务校验并依赖引用对象不可变；本阶段不增加摘要现行指针或覆盖更新行为。

此设计不承诺自动摘要质量、覆盖所有情节、准确抽取角色认知或保持语义等价。后续摘要审核、来源片段定位、替代关系、网站入口和受控上下文接入需要各自验收，不能以候选已保存冒充这些能力完成。
