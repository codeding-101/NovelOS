## M3 首个工作包完成记录

- `0004_task_runtime` 新增任务、依赖、执行尝试、不可变检查点和结果回执；内置人工与本地确定性校验两个执行者。
- `TaskEnvelope`／`ResultEnvelope` 1.0 明确输入版本和哈希、执行代次、期限、权限、完成原因、产物及证据。未知协议／执行者、非零外部用量被拒绝。
- 数据库持久队列提供同作品依赖、优先级、原子领取、60 秒领取期限、心跳、单次 1 小时上限、任务总期限与最多 5 次尝试。阻塞任务在调度限额之前过滤，避免遮挡可运行的前置任务。
- 人工中断可从检查点恢复，刷新接续轮换凭证；本地中断按有限退避重试。暂停、取消及过期使旧尝试失效；恢复拒绝已变更输入或失败依赖。
- 创建／检查点／结果幂等；状态、回执和审计同事务提交。迟到或越界结果隔离，不完整结果暂停，成功仅接收候选，不改写正文。
- 网站 `/tasks` 支持创建、领取、检查点、接续、暂停／恢复／取消、执行记录和候选查看，展示最近 100 个任务。执行者凭证不会进入任务详情或审计。
- Worker 分别处理文件／索引同步与任务步骤，失败相互隔离；不发起真实 API、Agent 或付费调用。

## M3 预算基础工作包完成记录

- `0005_work_budgets` 增加作品累计预算、调用预留及不可变账本，不自动创建额度或启用外部调用。已有任务升级后仍可读取与领取。
- 每作品固定 CNY／USD 币种，以整数微单位记录费用，并同时约束累计 token；没有浮点扣账、自动换汇或月度清零。
- 内部调用接口按任务锁、预算锁的顺序完成预留与发起登记；预留去重，预算不足不登记新调用，降额后重新检查发起条件。
- 取消／暂停／过期只释放确定尚未登记发起的额度。可能已发生费用的调用转 UNKNOWN 并保留占用，冻结该作品新调用，阻止相关任务恢复。
- 按执行者和回执标识去重结算；跨作品并发重复回执只能入账一次。实际费用超出预留时如实记录，超限后阻止新增调用。
- 网站 `/budgets` 提供额度配置、余额、调用分页、待对账筛选、人工核对及最近账本记录。预算编辑有版本冲突保护，对账不自动恢复任务或改变正文。
- 预算、调用状态、事件和审计同事务提交；不可变事件由数据库触发器保护。真实价格解析、供应商请求与外部 Agent 均未启用。
