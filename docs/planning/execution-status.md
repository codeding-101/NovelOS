## M1 已交付

- 新后端入口 `app.platform.api:create_app --factory`，与旧模型、旧库和旧业务路由隔离。
- PostgreSQL／SQLite 开发双方言、独立 Alembic schema、显式升级、启动预检与拒绝无版本已有数据库。
- 单用户初始化、Argon2id 密码哈希、持久会话、CSRF／来源校验、持久登录限流和安全 Cookie。
- 服务端 Fernet 凭证加密，API 仅返回元数据，校验及错误响应不回显提交的密钥。
- 独立 Agent 凭证模型；尚未签发执行权限或开放 Agent 任务接口。
- 独立 Worker 心跳、健康和就绪接口、能力状态；任务执行能力明确为未开放。
- 登录与工作空间控制台，凭证新增／删除和会话退出；桌面及手机布局。
- 只读旧库盘点工具、部署指南、M1 架构记录及 GitHub CI 配置。

## 当前边界

新平台已开放草稿编辑，尚无 AI 创作、可恢复任务或朱雀调用；保存凭证不会发起外部调用，也不意味着执行者已接通。旧代码及原工作区修改保留，但旧工作台不作为新生产服务的入口。新平台从未把未检测正文标为定稿。

## M2 首个工作包（此前交付）

- 新增独立迁移 `0002_work_assets`，作品、卷章场景、资料与原稿记录全部进入新平台库。
- 新增 `/works` 网站入口：作品列表、目录、编辑器、历史预览、版本比较、恢复、草稿导出、原稿导入及最近操作。
- 正文和标题每次保存生成不可变版本。原子版本比较阻止陈旧覆盖，恢复追加新版本，事务回滚不会推进版本号。
- 同事务审计；数据库触发器保护历史正文和原始上传字节；API 与数据库均不允许将版本升级为定稿。
- UTF-8 TXT／Markdown 导入保留原始字节；草稿 ZIP 包含历史正文、原文件、元数据及 SHA-256 清单。
- 旧库仍仅只读盘点，不实际迁移。现有六个用户修改文件不纳入本轮改动。

M1 的 Docker／HTTPS／卷持久化退出项尚未完成；本轮只推进可独立验证的 M2 本地工作包，不将项目标为已完成服务器部署或阶段完整验收。
