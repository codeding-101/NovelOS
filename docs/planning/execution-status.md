## M3 预算基础工作包完成记录

- `0005_work_budgets` 增加作品累计预算、调用预留及不可变账本，不自动创建额度或启用外部调用。已有任务升级后仍可读取与领取。
- 每作品固定 CNY／USD 币种，以整数微单位记录费用，并同时约束累计 token；没有浮点扣账、自动换汇或月度清零。
- 内部调用接口按任务锁、预算锁的顺序完成预留与发起登记；预留去重，预算不足不登记新调用，降额后重新检查发起条件。
- 取消／暂停／过期只释放确定尚未登记发起的额度。可能已发生费用的调用转 UNKNOWN 并保留占用，冻结该作品新调用，阻止相关任务恢复。
- 按执行者和回执标识去重结算；跨作品并发重复回执只能入账一次。实际费用超出预留时如实记录，超限后阻止新增调用。
- 网站 `/budgets` 提供额度配置、余额、调用分页、待对账筛选、人工核对及最近账本记录。预算编辑有版本冲突保护，对账不自动恢复任务或改变正文。
- 预算、调用状态、事件和审计同事务提交；不可变事件由数据库触发器保护。真实价格解析、供应商请求与外部 Agent 均未启用。
