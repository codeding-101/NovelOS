# NovelOS 产品与开发规划

编制日期：2026-10-23（Asia/Shanghai）

状态：需求基线与开发方案；不表示功能已经实现。

NovelOS 面向个人，以部署到服务器的网站为主要形态，为长篇小说的 AI 创作提供统一运行环境、控制平台和工作流程。模型 API、外部 Agent 与用户是执行者；作品资产、正式记忆、任务状态和规则由 NovelOS 持久管理。

## 方案中的工程建议

FastAPI、Next.js、PostgreSQL、独立 Worker、数据库任务队列及目录布局属于本次工程方案，不是用户已经指定的技术要求。实施中可以通过架构决策记录调整，但必须维持需求、资产可迁移性和验收标准。

首个个人生产版本包含完整创作闭环、真实执行者接入、朱雀门禁、故障恢复、备份恢复和百万字规模验证。此前阶段只交付内部预览能力；模拟检测不能使生产正文获得“已定稿”状态。

## 初始规划轮次的交付边界

- 仅新增本目录的四份 Markdown 文档。
- 不修改业务代码、现有 README、数据、密钥、部署配置或已有工作区修改。
- 不创建提交、不推送 GitHub、不删除远端内容、不改写历史。
- 后续重组通过普通增量提交实施；已有文档保留历史语境，新需求以本目录为重组基线。

尚未指定的模型供应商、服务器规格、费用上限及执行者凭证，以配置项和实施时输入处理，不阻塞规划。生产运行前必须填写预算、审批和数据外发规则。
